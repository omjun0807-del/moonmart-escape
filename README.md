# MOON MART: 심야 탈출

**EP.01 · v1.0 RC (출시 후보)** — 설치 없이 즐기는 한국어 웹 방탈출 게임

▶ **[웹게임 실행](https://omjun0807-del.github.io/moonmart-escape/?v=10)**

## 게임 소개

심야의 편의점에 홀로 남은 플레이어가 계산대, 창고, 관리실의 단서를 모아 잠긴 셔터를 해제하는 싱글플레이 퍼즐 게임입니다.

- 탐색: 매장 / 창고 / 관리실, 조사 지점 및 주변 탐색 목록
- 퍼즐: 계산대, 창고 전력, 스캐너, 공구함, CCTV 시간순 정렬, 비상 제어
- 기능: 아이템 선택·사용, 확대·드래그·방향 이동, 자동 저장, 단계별 힌트, 새 게임
- v1.0 RC: **사물별 전용 확대 일러스트**, 저장 기록에 따라 열리는 **사건 일지**, 엔딩의 마지막 기록 버튼
- v0.9: 퍼즐 진행도에 따라 변화하는 서랍·문·전력·셔터의 장면 효과
- v0.8: 매장·창고·관리실 게임 전용 SVG 배경 및 조사 위치 조정

## 배포

GitHub Actions `.github/workflows/deploy.yml`가 v0.8 ZIP 베이스와 `v09-world.js/css`, `v10-experience.js/css`를 결합해 GitHub Pages에 배포합니다. v1.0은 기존 v0.9 저장 형식을 변경하지 않았습니다. `main`에 배포 관련 파일을 커밋하면 자동으로 재배포됩니다.

현재는 **출시 후보(RC)**입니다. PC와 모바일 Chromium 에뮬레이션에서의 자동 검사와 GitHub Pages 게시 검사는 통과했지만 **실제 iPhone Safari 실기기에서 v1.0을 직접 확인하지는 않았습니다.**

## 알려진 한계

- **독립 게임 배경 3종은 2D SVG 일러스트**입니다. 실사풍 3D 게임 그래픽이 아닙니다.
- 확대 화면은 일부 조사 물건의 HTML/CSS 일러스트를 개선한 것으로, 배경의 모든 물건이 개별 3D 모델로 구성되지는 않았습니다.
- 저장은 현재 접속한 브라우저의 `localStorage`에 보관됩니다.
- 실사 사진 모드는 외부 Unsplash 연결 상태에 따라 표시되지 않을 수 있습니다. 기본값은 외부 연결이 필요 없는 게임 일러스트입니다.
- 온라인 멀티플레이와 서버 계정 동기화는 지원하지 않습니다.

게임 파일을 수정할 때는 기존 탐색·퍼즐·저장 기능을 모두 유지한 채 자동 테스트를 통과시킨 후 배포해 주세요.
