# MOON MART: 심야 탈출

**EP.01 · v0.4 베타** — 설치 없이 PC와 모바일 브라우저에서 플레이하는 한국어 1인용 웹 방탈출 게임

**게임 플레이:** https://omjun0807-del.github.io/moonmart-escape/

## 현재 플레이 방법

1. 매장과 창고를 조사해 단서를 수집합니다.
2. 인벤토리에서 아이템을 **한 번 눌러 선택**한 뒤 사용할 물건이나 문을 누릅니다. 잘못된 조합은 적용되지 않습니다.
3. 아이템의 ⓘ 버튼을 누르면 상세 설명을 확인할 수 있습니다.
4. 관리실의 CCTV 기록 네 장을 **촬영 시간 순서로** 복원해야 셔터 단말기가 열립니다.
5. 세 구역의 기호를 조합해 정문으로 탈출합니다.

브라우저의 localStorage에 플레이 기록을 자동 저장합니다. 기존 v0.3 세이브는 v0.4 실행 시 이어서 사용할 수 있도록 마이그레이션합니다.

- 1440px 데스크톱, 390px 및 320px 모바일 Chromium 자동 시나리오 테스트

### v0.3
- 매장/창고/관리실, 인벤토리, 키패드, 자동 저장, 좌우 탐색

## 코드 및 배포

- `index.html`: 현재 게임 소스코드
- `theme-v4.css`: v0.4 기능 그래픽과 인터랙션
- `MOON_MART_*.zip`: 초기 v0.3 배경 및 기본 CSS 파일 번들
- `.github/workflows/deploy.yml`: GitHub Pages 자동 배포

**코드 업데이트 시** main 브랜치의 `index.html` 또는 `theme-v4.css` 파일만 수정하고 커밋하면 자동으로 재배포됩니다. 초기 ZIP은 지우지 마세요. 그 안의 이미지와 기존 CSS를 배포에 계속 사용합니다.

## 남은 검증

v0.4는 Chromium 자동 테스트를 수행한 베타입니다. **실제 iPhone Safari v0.4 테스트는 아직 미확인**입니다. v0.3 버전은 사용자 PC/아이폰에서 정상 플레이된 기록이 있습니다. AI 배경에 잘못 생성된 한글과 낮은 해상도도 추후 개선해야 합니다.
