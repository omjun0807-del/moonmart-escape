## 게임 방식

밤 00:13, 잠긴 편의점에서 계산대 → 창고 → 관리실의 단서를 모아 비상 셔터를 해제하는 포인트 앤 클릭 방탈출입니다. 제한 시간이나 게임오버는 없고 자동으로 진행 상태를 저장합니다.

- 계산대 암호, 창고 열쇠, 분전반, 스캐너, 공구함, CCTV 기록 정렬, 비상 셔터 기호 등 6개 이상의 연결 퍼즐
- 아이템 선택·사용, 조사 확대·이동, 단계별 힌트, 사건 일지, 방 간 이동

- v0.9~v1.1: 퍼즐 해결 상태에 따른 장면 변화와 실제 조사 버튼 좌표에 맞춘 그래픽
- v1.2: 몰입 보기(F) 및 원래 화면으로 돌아오기

## 몰입 보기 사용법

상단 **몰입 보기** 버튼을 누르면 주변 메뉴가 숨겨지고 게임 화면이 커집니다. 화면 아래쪽 전용 메뉴에서 **주변 조사 / 가방 / 사건 일지 / 도움말**을 실행할 수 있습니다. 인벤토리에서 아이템을 선택하면 패널이 닫히고, 탐색 메뉴에서 사용할 곳을 누르면 됩니다. PC에서는 **F** 키로 전환하고, **Esc**로 닫을 수 있습니다.

## 진행 기록 백업

기본적으로 진행 상태는 현재 브라우저의 로컬 저장 공간(`localStorage`)에만 저장됩니다. 게임 메뉴 아래쪽 **진행 기록 백업 · 불러오기**를 열면 `.json` 파일로 내보내거나 복원할 수 있습니다. 불러오기 전에 현재 기록을 별도 로컬 키로 보관하며, 백업의 형식과 용량을 검증합니다. 불러온 진행 상태는 다음 페이지의 게임 로직이 실행되기 **전** 복원해 종료 시 자동 저장과 충돌하지 않게 합니다. 게임 저장 파일은 외부 서버로 업로드하지 않습니다.

## 알려진 한계

- 배경은 **2D SVG 게임 일러스트**입니다. 실사풍 고품질 새 배경은 아직 제작되지 않았습니다. 실제 없는 `art-v12/` 이미지가 게시된 것처럼 안내하지 않습니다.
- 일부 '실사 사진' 모드 이미지는 외부 서비스의 네트워크 상태에 따라 로딩되지 않을 수 있습니다.
- **아이폰 Safari 실기기 테스트는 미실시**입니다. WebKit 엔진 자동 검사와 실기기 검증은 구분해야 합니다.
- 온라인 계정 동기화나 멀티플레이는 지원하지 않습니다.
