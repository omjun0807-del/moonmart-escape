# MOON MART v0.5 — QA (2026-10-13)

## 구현
- 계산대 서랍 개방 시 열쇠 등장 애니메이션
- 창고·관리실 진입 시 문 열림 시각 효과
- 전력 복구 시 조명 깜박임 연출
- 비상 셔터 해제 시 상승 애니메이션
- 문·서랍·전력·셔터별 WebAudio 효과음 (기본 음소거)
- 기존 v0.4 저장 키 및 퍼즐 정답·상태 유지
- 동작 줄이기(prefers-reduced-motion) 지원

## 실제 테스트
- Chromium 브라우저 엔진, 1440×900 / 390×844 / 320×660
- 자동 클릭으로 영수증 → 계산대 → 창고 → 분전반 → 스캐너 → 공구함 → 관리실 → CCTV → 단말기 → 탈출 엔딩 완료
- JS pageerror 0건, 페이지 가로 넘침 없음
- localStorage 모의 객체를 사용하여 상태 저장 직후 데이터 생성 확인

## 미검증
- 배포된 실제 HTTPS 주소에서의 엔드투엔드 조작
- 실기기 iPhone Safari
- 탭 종료/재접속 후 자동 저장 복구
- 별도의 고해상도 장면 3종 제작 (v0.5에는 포함하지 않음)
