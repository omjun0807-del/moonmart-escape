### 중요한 제한

- Chromium 모바일 에뮬레이션은 **아이폰 Safari 실기기 테스트가 아닙니다.**
- GitHub Actions Pages 빌드 및 게시 성공은 실제 모바일 터치와 모든 기능이 정상임을 뜻하지 않습니다.
- 현재 그래픽의 배경 3개는 v0.3의 이미지 그대로이며, AI 생성 글자 오류와 배경 해상도 개선은 다음 단계입니다.
- 외부 테스터를 통한 사용성 평가, 성능 프로파일링, Safari 실기기 QA는 미완료입니다.

## 실기기에서 확인할 동작

1. 00:13 시작 화면에서 게임 시작.
2. 영수증과 메모를 찾은 뒤 계산대를 해제.
3. 인벤토리에서 창고 열쇠 선택 → 창고 문 선택.
4. 분전반 순서 복구 → 건전지 선택 → 스캐너에 사용.
5. 공구함 열기 → 카드 선택 → 관리실 문 사용.
6. CCTV 네 장을 오래된 촬영 시간 순서로 재구성.
7. 셔터 단말기 조작 → 정문 탈출.
8. 중간에 페이지 새로고침 후 이어하기 확인.

오류가 발견되면 사용한 기기와 발생 지점, 화면 캡처를 기록해 수정합니다.
