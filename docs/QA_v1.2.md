# MOON MART v1.2 변경 기록

## 구현
- v1.2 `몰입 보기` 모드 추가: 우측 메뉴를 숨기고 게임 장면을 크게 볼 수 있습니다.
- 모바일(390px·320px)에서도 버튼이 표시되도록 CSS를 별도 지정했습니다.
- 원래 화면으로 돌아오는 버튼과 키보드 F / Escape 조작 지원.
- 몰입 보기 설정은 브라우저에 따로 저장하며 기존 퍼즐과 진행도는 바꾸지 않습니다.
- 신규 고해상도 게임 장면이 **세 구역 모두 실제 게시된 경우에만** 해당 선택 버튼을 활성화하는 안전 장치를 만들었습니다.
- 전 단계 v1.1에서 제작된 사물 연출, v1.0 사건 일지, 기본 퍼즐, 저장 로직 유지.

## 미완료
- v1.2에서 목표로 했던 새 시네마틱 매장·창고·관리실 배경은 **실제 생성하지 못했습니다**.
- 이미지 생성 서버에 독립 배경 3건을 요청했으나 세 건 모두 실패했고, 다른 생성 도구는 무료 요금제에서 접근이 제한됐습니다.
- 따라서 v1.2에서는 **기존 v0.8 게임 전용 일러스트가 계속 기본으로 표시됩니다**.
- 나중에 별도 배경 3장이 완성되더라도 이미지 품질과 실제 조사 위치를 검수한 뒤 출시해야 합니다.
- 아이폰 Safari 실기기는 아직 직접 검증하지 못했습니다.
