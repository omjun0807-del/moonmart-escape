# v1.3 검증 기록 — 몰입 모드 완전 조작 및 저장 백업

## 실제 변경
- `v13-playable-focus.css`: 몰입 보기 하단 메뉴, 원본 가방·탐색·힌트 패널을 재활용하는 팝업, 터치/키보드 대응, 백업 보관함.
- `v13-playable-focus.js`: 주변 조사/가방/사건 일지/도움말 진입, 기존 퍼즐 엔진의 아이템 사용 동작을 그대로 연결, ESC 및 배경 클릭으로 메뉴 닫기.
- 가방 클릭 즉시 기존 렌더 함수가 DOM 요소를 교체하므로 이벤트 **캡처 단계**에서 클릭을 감지해 메뉴를 닫도록 수정.
- 기록 백업: 원본 게임 데이터 `moon_mart_escape_ep01_v1` 내보내기, JSON 유효성 검사, 이전 기록 별도 로컬 백업, 복원 후 새로고침.
- 진행 데이터 스키마는 변경하지 않았고 기존 저장과 자동 저장을 유지함.
